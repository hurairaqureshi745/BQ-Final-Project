# Digital Sphere

Modern React + Vite project structure for the Digital Sphere premium digital agency website.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` checks JavaScript and JSX with ESLint.
- `npm run preview` previews the production build locally.

## Structure

- `src/components` reusable UI and site components.
- `src/pages` route-level page components.
- `src/layouts` shared page shells.
- `src/assets` static imported assets.
- `src/hooks` reusable React hooks.
- `src/utils` shared constants and helpers.
- `src/data` content/configuration data.
- `docs/component-hierarchy.md` full component hierarchy and reusable component suggestions.

## Current Scope

This phase intentionally contains semantic React structure only. No CSS or animations are included.
